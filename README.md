# DHCP Configuration

A simple **DHCP (Dynamic Host Configuration Protocol)** implementation created using **Cisco Packet Tracer**.

## 📌 Project Overview

This project demonstrates how a **Cisco router provides IP addresses automatically** to client devices using DHCP.

### 🛠️ Technologies Used

* Cisco Packet Tracer
* Cisco IOS
* DHCP
* IPv4

### 🔹 Features

* DHCP pool configuration
* Automatic IP address assignment
* Default gateway configuration
* DNS server configuration
* Connectivity testing using `ping`
